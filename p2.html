For project 2 we had a lot of different parts that went into the final version. When I started this project I originally used the Penrose tiles as my second algorthm along with the sine waves. However it became a bit difficult to use when it came to the different acts. When adding it to the different acts and then adding the sine waves on top of the penrose, the waves would be drawn in the same way the penrose were being drawn. I tried using Gemini to help me so that the waves weren't drawn. Phase 1

For the first part of this project we were put into groups and were given a list of different algorithms to choose from. We each found one that we liked and were tasked with playing and getting to know and understand how the algorithm worked. As a group we chose the Recursive Tree to each figure out how to change it as much as possible so that it resembled less of a tree and more of something else. The algorithm that I choose to look at was the Penrose Tiles. The origiinal code was black and white and was very geometrical. The first thing I wanted to change was by adding color to the tiles. Through this as it continues to draw the color is randomly generated, moving through the colors of the rainbow at a steady pace. After I started playing with the different shapes, adding more tiles, changing the angles and positions as well as slowing or speeding up the drawing process. When I finished playing with the algorithm I liked how the penrose started looking like a paint splotch.

Phase 2

In this next phase we were introduced to sine waves. We learned how to create ifferent types of waves, changing their properties and using them to create different patterns and movements. For this phase I started playing with the sines and seeing how I could change them. We were also tasked with adding atleast one different algorithm to the project. I added the Penrose tiles that I used in phase 1. Using this algorithm with the sine waves was a bit difficult since the penrose tiles themselves had a lot of setup. I kept the original penrose tiles with the color that I added. However when adding the sinewaves on top of the penrose, it would act as if drawing the wave, causing the wave to spiratically move randomly across the screen. I wasn't sure how to fix this but I ended up liking the last act which tied the whole project together, making it more cohesive.
