Project 4

"'We tell kids, Go out and have an adventure, but give animals their space.'"- Chris Kratt, Kratts' Creatures 1996
Exercise 5

In this project we started learning about Libraries and SceneManager. This exercise is the starter/base for project 4. Giving us ideas and themes of what to do for the project. We did a speed dating game with our classmates where we gave eachother ideas and also shared our starting ideas, getting feedback and also helping people create ideas. My original idea for this was to create an adventure, interactive game about 2 puppies. Its a short story that I made up when I was in second grade as a bedtime story to my dad. Later I made an animation for a previous project I had worked on. However due to it being an interactive game I wasn't sure if I had the time or the coding skills needed in order to create what I wanted.

For this project I changed my idea from a story game adventure to an interactive and informative website. I got this idea from one of the student examples shown in class. I choose to create an informative website about mythologies. Specifically mythological creatures that were inspired by real animals(living or extinct). In this example we were told to play and choose a library and make sure we understood how to use the scene manager, libraries and sounds for the final.

Project 4

This is the final version of my Project 4. Similar to Exercise 5 I took that as a base and added more scenes and creatures/animals. I choose to use the p5Play and p5Touchgui for my added libraries. For sound I added more sounds to add atmosphere. Both music and creature sounds. I really wanted to focus on sound to create an almost eerie yet fantasy styled vibe. There are 3 mythological creatures and 4 animals that inspired those creatures. I added infomation and detailof the different creatures and animals. For the creatures I also added some mytholigical background of where they came from and how they came to be. With the animals I wanted to make sure it was obvious of how they became the inspiration.

The biggest part of this project was using mythologies and animals that are less common. I didn't wanna use a well known one such as the unicorn. I choose the Basilisk, Cyclops and the Mapinguari. For the wire frame I sketched out what I wanted the website too look like for each scene. Such as the home, help and list page. I had a few rough sketches of what I wanted the creature and animal pages to be.

I liked working a lot on this project because I've loved animals ever since I was a kid. I grew up watching a lot of animal shows and documentaries. The animals in this project are less known and also have some fun facts about. To make it more game like I added some death screens to make it more interactive and engaging. Making the mythologies feel more real because they came from real animals.
