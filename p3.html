Phase 1

Project 3 phase 1, we learned about grid arrays. We learned how to create various grid arrays using colored pixels, text and images in order to create pixel like art. When starting the first phase I wasn't sure what to make. When making the first color pixel grid, I started "drawing" and eventually I remade a simple 2d drawing I did of a meteor in space. I decided to stick with space as a theme and eventually created multiple arrays showing different aspects of space. For this first phase I made 2 different imagines using different grid arrays. I decided to stick with the the same color palette to make it easier. I ended up making 2 colored arrays, 2 text arrays and 2 image arrays. For the text arrays I used different words for both the planet and meteor. For the image array I looked at various images and found different colored images of multiple meteors and planets.

Phase 2

For the final phase of project 3 we made more arrays and created different pages. On the first page we simply used it as a text page to introduce the next pages as well as our groupmates. On the first page we included our phase 1 arrays. On the second page we were to create 4 more arrays and alter or create new ones. I decided to stick with the space theme for my color pixel array. For this one I decided to play with the different shapes and see how I could change the layout. My other arrays are both image arrays, using images from Pokemon to create Pikachu and Oshawatt. Originally I wanted to stay with the space theme but I also wanted to try something different. For my Oshawatt array i was able to make the individual pixals move. Oshawatt is a water type and the movement of the array looks like its underwater. For the other Pikachu array, I decided to take the bouncing movement from Exercise 3/4.
